# Nu Da Trading PLC Landing Page

A clean React + Tailwind CSS landing page template for Nu Da Trading PLC, a plywood supplier based in Addis Ababa.

## Run locally

```bash
npm install
npm run dev
```

## Project structure

```text
src/
  assets/
    nuda-plywood-hero.png
    nuda-logo-transparent.png
  components/
    Header.jsx
    HeroSection.jsx
    AboutSection.jsx
    ProductsSection.jsx
    ProcessSection.jsx
    MissionSection.jsx
    ContactSection.jsx
    LocationSection.jsx
    Footer.jsx
  data/
    siteContent.js
  App.jsx
  index.css
  main.jsx
```

Edit `src/data/siteContent.js` for repeated business content. Edit individual files in `src/components/` for section layout. Tailwind theme colors and small custom animations live in `src/index.css`.

## Sections included

- Fixed navigation
- Visual hero section
- Company highlight cards
- Plywood product strengths
- Supply process section
- About/company section
- Office location call to action
- Footer
